## 1. 📌 Ringkasan Eksekutif & Nilai Bisnis (Why This Website Stands Out)

**CV Berkat Mandiri** adalah perusahaan manufaktur dan distribusi pengemasan industri terkemuka di Indonesia yang memproduksi tiga lini produk utama:
1. **Karung Goni Alami (*Natural Jute Sacks / B-Twill*)** berstandar ekspor komoditas agrikultur (kopi specialty, kakao, dan rempah-rempah).
2. **Karung Plastik PP Woven (*High-Density Polypropylene*)** untuk muatan beban berat (beras, pupuk kimia, gula, semen, dan pakan ternak).
3. **Karung Laminasi BOPP (*Custom Printing*)** beresolusi tinggi dengan teknologi rotogravure untuk display retail supermarket premium.

Platform digital ini dirancang khusus dari sudut pandang **Principal Solutions Architect** dan **Product Marketing Specialist** untuk menjembatani perdagangan B2B skala internasional dengan efisiensi manajemen rantai pasok internal:

* **Membangun Otoritas & Kredibilitas Internasional:** Menghilangkan keraguan pembeli korporat (*corporate buyers*) dan manajer pengadaan luar negeri (*foreign procurement managers*) melalui tampilan visual kelas dunia, transparansi kapasitas mesin loom, dan sertifikasi ekspor.
* **Mesin Akuisisi Pelanggan B2B Otomatis (Inbound Lead Engine):** Mengubah calon klien pasif menjadi prospek siap transaksi melalui **Kalkulator Logistik Kontainer Interaktif (FCL 20ft / 40ft HC)** dan **Formulir RFQ Terintegrasi WhatsApp Resmi**.
* **Integrasi Hulu-Hilir Tanpa Hambatan (ERP Terpadu):** Menghubungkan etalase publik langsung ke sistem operasional gudang, kalkulasi gaji borongan per lembar karung, otomatisasi Surat Jalan kurir armada, hingga prediksi kebutuhan stok berbasis **Machine Learning (AI)**.

> [!NOTE]
> Website ini dirancang untuk memberikan **First Impression** yang tak terlupakan bagi mitra bisnis korporat serta mempercepat siklus negosiasi ekspor dari hitungan minggu menjadi hitungan menit.

### 2.2. Keamanan Siber Tingkat Tinggi & Arsitektur 100% Server-Side

Keamanan sistem diperkuat dengan standar industri pertahanan berlapis (*Defense-in-Depth*) untuk melindungi kerahasiaan data operasional dan transaksi perdagangan:

```
[ Browser Klien / Publik ]
            │
            ├─► (1) Kunjungan Halaman ──► [ Next.js React Server Component (RSC) ]
            │                                     │
            │                                     ├─► Kueri Langsung Neon PostgreSQL (Prisma)
            │                                     └─► Komunikasi Tertutup ke ML Service
            │
            │◄── (2) Render HTML Utuh (Nol URL API, Nol Payload Sensitif di Network Tab)
            │
            └─► (3) Submit Form / Aksi ──► [ Next.js Server Actions ]
                                                  │ (Verifikasi CSRF + Honeypot + Rate Limit)
                                                  └─► revalidatePath() ──► Update Instan
```

* **Zero Client-Side API Exposure:** Seluruh data dashboard, metrik penjualan, katalog gudang, dan rekonsiliasi upah diambil melalui **React Server Components (RSC)**. Tab *Network (Fetch/XHR)* pada browser tidak menampilkan endpoint API internal, kueri database, maupun API key eksternal.
* **Isolasi Mutlak `server-only`:** Driver database Neon PostgreSQL dan pustaka keamanan dienkapsulasi menggunakan pustaka `server-only` sehingga mustahil bocor ke dalam bundle JavaScript peramban.
* **Pertahanan Terhadap OWASP Top 10:**
  * **Anti-Injection & XSS Sanitization:** Utilitas sanitasi `sanitizeString` dan `sanitizeText` membersihkan input pengguna dari payload tag HTML berbahaya dan script injection.
  * **Anti-CSRF & Origin Verification:** Lapisan middleware dan fungsi `verifyRequestOrigin` memvalidasi integritas header `Origin` dan `Host` pada setiap mutasi data (`POST`, `PUT`, `DELETE`).
  * **Anti-Scanning & Probe Blocking:** `middleware.ts` secara otomatis memblokir bot pemindai eksploitasi umum (`.env`, `.git`, `.neon`, `wp-admin`, `phpmyadmin`, `xmlrpc`, dll.) pada level Edge.
  * **Honeypot Bot Trap:** Kolom tersembunyi `website_hp` pada formulir RFQ mendeteksi dan secara diam-diam menggagalkan spammer bot otomatis tanpa mengganggu pengguna nyata.
  * **In-Memory Sliding Window Rate Limiting:** Pembatasan frekuensi request per alamat IP untuk mencegah serangan brute-force dan penumpukan traffic (DoS).
  * **Error Masking:** Seluruh pesan kegagalan database ditutupi dengan pesan generik yang aman (`maskError`) guna mencegah kebocoran informasi arsitektur (*Information Disclosure*).
* **HTTP Security Headers Kelas Bank (A+ Grade):**
  * `Strict-Transport-Security: max-age=63072000; includeSubDomains; preload` (HSTS)
  * `Content-Security-Policy` (CSP menyeluruh dengan pembatasan domain sumber)
  * `X-Frame-Options: DENY` (Perlindungan mutlak anti-Clickjacking)
  * `X-Content-Type-Options: nosniff` (Perlindungan anti-MIME sniffing)
  * `Referrer-Policy: strict-origin-when-cross-origin`
  * `Permissions-Policy: camera=(), microphone=(), geolocation=()`

### 2.3. Dominasi Mesin Pencari (Technical SEO) & Performa Kilat

Website dioptimasi secara komprehensif agar memenangkan persaingan pencarian organik Google tanpa ketergantungan biaya iklan berbayar:

* **Struktur Data Terverifikasi (Schema.org JSON-LD):** Menanamkan metadata graph multi-entitas (`Organization`, `LocalBusiness`, `WebSite`, `OfferCatalog`, dan `Product`) yang memudahkan Google menampilkan *Rich Snippets* harga, spesifikasi, dan legalitas perusahaan.
* **Pratinjau Sosial Media Eksklusif (Open Graph 1200x630):** Tautan otomatis menghasilkan kartu pratinjau elegan beresolusi tinggi saat dibagikan ke WhatsApp, LinkedIn, atau email.
* **Sitemap Otomatis & Robots Terkendali:** `sitemap.xml` dinamis diperbarui berkala dengan prioritas tinggi, sementara `robots.txt` mengunci seluruh rute ERP internal (`/dashboard`, `/inventory`, `/sales`, `/employees`, `/reports`, `/api`) agar terlindungi dari pengindeksan publik.
* **Performa Core Web Vitals Ekstrem:**
  * **Largest Contentful Paint (LCP) < 1.2 Detik:** Konten utama dimuat seketika melalui SSR.
  * **Cumulative Layout Shift (CLS) = 0.00:** Nol pergeseran tata letak halaman saat loading.
  * **Font Optimization:** Menggunakan Google Fonts `Geist` dengan konfigurasi `display: swap`, `dns-prefetch`, dan `preconnect`.

## 6. 🛠️ Panduan Pengelolaan Sistem (Quickstart & Administration Guide)

### 6.1. Prasyarat Lingkungan (Prerequisites)
* **Node.js:** Versi `v20.x` atau lebih baru
* **Python:** Versi `3.10+` (untuk menjalankan service prediksi stok lokal)
* **PostgreSQL:** Akun database aktif (Neon Serverless PostgreSQL disarankan)

### 6.2. Menjalankan Sistem di Lingkungan Lokal (Local Development)

1. **Kloning Repositori & Masuk ke Folder Proyek:**
   ```bash
   git clone https://github.com/syahrizaalsistani/berkat-mandiri.git
   cd berkat-mandiri/berkat-mandiri
   ```

2. **Instalasi Dependensi Node.js:**
   ```bash
   npm install
   ```

3. **Konfigurasi Environment Variables:**
   Buat file `.env` pada folder root proyek dan lengkapi konfigurasi berikut:
   ```env
   # Basis Data Neon Serverless PostgreSQL
   DATABASE_URL="postgresql://neondb_owner:YOUR_PASSWORD@YOUR_HOST/neondb?sslmode=require"

   # URL Microservice Machine Learning (Lokal atau HuggingFace Spaces)
   PYTHON_ML_SERVICE_URL="http://localhost:8000"

   # Token Rahasia Webhook Bot WhatsApp (Opsional untuk keamanan bot)
   BOT_WEBHOOK_SECRET="your-ultra-secure-random-secret-token"
   ```

4. **Sinkronisasi Skema Basis Data (Prisma ORM):**
   ```bash
   npx prisma generate
   npx prisma db push
   ```

5. **Menjalankan Server Pengembangan (Next.js + Python ML Secara Bersamaan):**
   ```bash
   npm run dev
   ```
   Aplikasi Next.js akan aktif di `http://localhost:3000` dan Microservice Python ML akan aktif di `http://localhost:8000`.

### 6.3. Membangun Bundle Produksi (Production Build & Verification)

Sebelum melakukan deployment, pastikan seluruh kode lolos verifikasi kompilasi produksi:

```bash
npm run build
```
